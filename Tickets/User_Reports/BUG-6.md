While Phase 1 character replacement rules are correctly followed (any face card can be exchanged for any other drawn face card being played to that stack), there is currently no correct implementation for the Phase 2 character replacement rules:

Jacks can be replaced only with Queens or Kings.
Queens can be replaced only with Kings.
Kings cannot be replaced.

Right now, in the second phase, you can "sidegrade" a jack to another jack, etc. 
You are also allowed right now to downgrade a character (e.g. replace a King with a Queen), neither of which are allowed per the official rules.


Finally, per the official rules, if a character dies (it's stack totally gone), you are allowed to replace it with a Jack only. This is also not currently implemented- there is not even a way to select the empty character stack to play a card to it.
